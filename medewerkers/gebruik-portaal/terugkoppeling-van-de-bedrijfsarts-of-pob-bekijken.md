# Terugkoppeling van de bedrijfsarts of POB bekijken

{% @supademo/embed url="https://app.supademo.com/demo/cmiecj0du02g7060ib3ez6rtf" demoId="cmiecj0du02g7060ib3ez6rtf" fullWidth="true" %}

Wil je teruglezen wat er tijdens je afspraak is besproken? Je vindt de terugkoppeling in Mijn ZekerArbo bij je documenten.

#### Zo vind je je terugkoppeling:

1. Log in op Mijn ZekerArbo via [www.zekerarbo.nl](http://www.zekerarbo.nl).
2. Klik op het dashboard op de kaart Documenten.
3. Zoek in de lijst naar het meest recente document met `TK` in de titel. `TK` staat voor terugkoppeling.
4. Klik op Download om het document te openen en te lezen.

{% hint style="info" %}
Het kan een paar dagen duren voordat je terugkoppeling in het portaal staat.

Zie je het document niet direct na je afspraak? Controleer later in de week opnieuw bij **Documenten**.
{% endhint %}
