# Ik heb een nieuwe telefoon of geen toegang tot de Authenticator app

Heb je een nieuwe telefoon en kun je daardoor niet meer bij je Google of Microsoft Authenticator app? Of werkt de app niet meer? Geen probleem. Je kunt nu tijdens het inloggen eenvoudig kiezen voor een verificatiecode per SMS.

Stappenplan: Inloggen met SMS

1. Ga naar Mijn ZekerArbo en vul je e-mailadres en wachtwoord in.
2. Het systeem vraagt nu om de code uit je Authenticator app.
3. Kun je hier niet bij? Scroll naar beneden en klik op de link "Of verzend code via SMS"&#x20;
4. Je ontvangt direct een SMS-code op het 06-nummer dat bij ons bekend is.
5. Vul deze code in en klik op Inloggen.

Ontvang je geen SMS? Komt de code niet binnen? Dan staat er waarschijnlijk een oud of onjuist 06-nummer in ons systeem. Vraag je werkgever om je telefoonnummer in het portaal aan te passen. Zodra dit is gebeurd, kun je het direct opnieuw proberen.
