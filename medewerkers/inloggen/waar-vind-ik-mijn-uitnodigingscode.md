# Waar vind ik mijn uitnodigingscode?

Wanneer ontvang ik de code? Je krijgt de mail met de code pas op het moment dat er daadwerkelijk een afspraak voor je is ingepland met een zorgprofessional. Heb je nog geen afspraak staan? Dan heb je ook nog geen code nodig.

Communicatie via het portaal Zodra je bent aangemeld, verloopt alle communicatie via jouw persoonlijke werknemersportaal: Mijn ZekerArbo.

In deze beveiligde omgeving kun je:

* Onze berichten lezen.
* Eenvoudig en veilig documenten delen met de praktijkondersteuner (POB) of de bedrijfsarts.
