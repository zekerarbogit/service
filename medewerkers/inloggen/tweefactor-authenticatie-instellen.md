# Tweefactor authenticatie instellen

{% @supademo/embed demoId="cmirk9a7h001p0d0idjc2oovn" url="https://app.supademo.com/demo/cmirk9a7h001p0d0idjc2oovn" %}

#### Stappenplan

1. Vul je e-mailadres en wachtwoord in en klik op Inloggen.
2.  Je ziet nu een QR-code op het scherm. Scan deze code met de Authenticator app op je telefoon.

    > Heb je de app nog niet?
    >
    > * [authenticator-app-installeren-iphone.md](authenticator-app-installeren-iphone.md "mention")
    > * [authenticator-app-installeren-android.md](authenticator-app-installeren-android.md "mention")
3. Na het scannen verschijnt er een 6-cijferige code in de app. Vul deze in op je scherm en klik op Authenticator Bevestigen.
4. Het systeem vraagt ter controle nogmaals om de code. Vul de (nieuwe) code uit de app in en klik op Inloggen.

Je bent nu veilig ingelogd. De volgende keer heb je alleen de code uit de app nodig.
