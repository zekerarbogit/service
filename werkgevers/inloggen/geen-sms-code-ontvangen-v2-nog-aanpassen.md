# Geen SMS code ontvangen V2 (nog aanpassen)

Wacht je op een verificatiecode per SMS om in te loggen, maar komt deze niet binnen? Door de migratie kan het zijn dat er een ander nummer in het systeem staat dan je verwacht.

Controleer eerst deze twee punten:

1. Telefoon van een collega: Deel je het account met meerdere mensen? Check of de SMS op de telefoon van een collega is binnengekomen.
2. Oud telefoonnummer: Heb je nog toegang tot een oud 06-nummer? Controleer of de code daarop is binnengekomen.

Nog steeds geen code? Kun je de code niet achterhalen of is het nummer onjuist? Stuur dan direct een e-mail naar onze contractadministratie.

* E-mail: [contractadministratie@zekerarbo.nl](mailto:contractadministratie@zekerarbo.nl)

Vermeld in de mail je naam, bedrijfsnaam, e-mailadres en het juiste 06-nummer. Wij passen dit dan handmatig voor je aan in het systeem.
