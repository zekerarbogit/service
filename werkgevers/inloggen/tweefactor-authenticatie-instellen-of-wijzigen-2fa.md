# Tweefactor authenticatie instellen of wijzigen (2FA)

Om de veiligheid van je gegevens in ZekerArbo Online te waarborgen, is het gebruik van tweestapsverificatie verplicht. Wil je overstappen van SMS naar de Authenticator app of andersom? Volg dan onderstaande stappen.

**Stappenplan**

1. **Ga naar de configuratiepagina** Klik op de volgende link om direct naar de 2FA-instellingen te gaan: [2FA Methode Wijzigen](https://portalzvdzsso.b2clogin.com/portalzvdzsso.onmicrosoft.com/oauth2/v2.0/authorize?p=B2C_1A_CHANGE_MFA\&client_id=e8060e2c-e5f7-4ee8-bd0d-409d73f648aa\&nonce=defaultNonce\&redirect_uri=https%3A%2F%2Fportaal.zekerarbo.nl\&scope=openid\&response_type=code\&prompt=login).
2. **Inloggen** Log in met je e-mailadres en wachtwoord.
3. **Identiteit controleren** Je identiteit wordt gecontroleerd via de methode die je op dit moment gebruikt (dit is de SMS-code of de Microsoft Authenticator app).
4. **Nieuwe methode kiezen** Nu kun je de nieuwe methode configureren. Je kunt kiezen uit:
   * Microsoft Authenticator app (Aanbevolen): Veilig en snel via een melding of code in de app.
   * Telefoon: Je ontvangt een code op je mobiele telefoon.
