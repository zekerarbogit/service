# Verzuimrapportage maken

{% @supademo/embed url="https://app.supademo.com/demo/cmo6xf08m0f5h37n2cb9v91xw" demoId="cmo6xf08m0f5h37n2cb9v91xw" fullWidth="true" %}

{% hint style="warning" %}
Werk je met een verzekeraar of een HR-koppeling? Dan zijn medewerkers zonder verzuim niet altijd automatisch bekend in het systeem.
{% endhint %}

### Belangrijk: Voorwaarde voor juiste cijfers:

In veel situaties kennen wij niet jouw volledige werknemersbestand. Wij ontvangen dan meestal alleen gegevens van medewerkers die ziek zijn of ziek zijn geweest.

Medewerkers zonder verzuim zijn dan vaak niet bij ons bekend. Daardoor weten wij niet automatisch:

* hoeveel medewerkers je in totaal in dienst hebt
* hoeveel FTE daarbij hoort

Wil je toch goed kunnen rapporteren? Vul dan onder **Vaste waardes** deze gegevens zelf in:

* **Aantal medewerkers**
* **Aantal FTE**

Zo kan ZekerArbo Online alsnog betere verzuimpercentages en kerngetallen berekenen.

{% hint style="info" %}
Vul `Aantal FTE` en `Aantal medewerkers` alleen in als niet alle medewerkers bij ZekerArbo bekend zijn.
{% endhint %}

#### Stappenplan:

{% stepper %}
{% step %}
### Open Rapportages:

Log in op ZekerArbo Online.

Klik links in het menu op `Rapportages`.
{% endstep %}

{% step %}
### Kies het rapportprofiel:

Klik op het keuzemenu.

Selecteer het gewenste rapportprofiel.

Kies daarna `Basis verzuimrapportage werkgever`.
{% endstep %}

{% step %}
### Vul vaste waardes in als dat nodig is:

Missen niet-verzuimende medewerkers in het systeem?

Vul dan onder **Vaste waardes** eerst `Aantal FTE` in.

Vul daarna `Aantal medewerkers` in.
{% endstep %}

{% step %}
### Kies de rapportageperiode:

Klik op het kalendericoon.

Selecteer de gewenste rapportageperiode.
{% endstep %}

{% step %}
### Selecteer het bedrijf:

Kies het bedrijf waarvoor je de rapportage wilt maken.
{% endstep %}

{% step %}
### Genereer de rapportage:

Klik op `Genereren`.
{% endstep %}

{% step %}
### Kies het exportformaat:

Kies `Verzuimrapportage Excel`, `Verzuimrapportage PDF` of `Verzuimrapportage per mail`.
{% endstep %}
{% endstepper %}

{% hint style="success" %}
Zo geregeld: na `Genereren` exporteer je de rapportage direct in het formaat dat je nodig hebt.
{% endhint %}
